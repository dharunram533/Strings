# 12. Compare Two Usernames

## Problem Statement

Write a C program to compare two usernames without using strcmp() and determine whether they are identical.

## Algorithm

1. Start the program.
2. Read the first username.
3. Read the second username.
4. Compare the characters of both strings one by one.
5. If all characters are equal and both strings have the same length, they are identical.
6. Otherwise, they are different.
7. Display the result.
8. Stop the program.

## Sample Input

Username 1: user123
Username 2: user123

## Sample Output

Both usernames are identical.
