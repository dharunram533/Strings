# 31. Palindrome Using User-Defined Function

## Problem Statement

Write a C program to determine whether a string is a palindrome using a user-defined function.

## Algorithm

1. Start the program.
2. Read the string.
3. Pass the string to a user-defined function.
4. Compare characters from the beginning and end.
5. Continue until the middle of the string is reached.
6. If all corresponding characters are equal, the string is a palindrome.
7. Otherwise, it is not a palindrome.
8. Display the result.
9. Stop the program.

## Sample Input

LEVEL

## Sample Output

LEVEL is a palindrome.
