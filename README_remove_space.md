# 11. Remove Spaces from String

## Problem Statement

Write a C program to remove all spaces from a product serial number entered by the user.

## Algorithm

1. Start the program.
2. Read the product serial number.
3. Traverse each character.
4. Check whether the character is a space.
5. Ignore spaces.
6. Store or display all other characters.
7. Display the serial number without spaces.
8. Stop the program.

## Sample Input

AB 12 CD 45

## Sample Output

AB12CD45
