# String Length Using fgets()

## Problem Statement

Write a C program to read a string using fgets() and find the number of characters in the string.

## Algorithm

1. Start the program.
2. Declare a character array to store the string.
3. Read the string using fgets().
4. Initialize a counter variable to 0.
5. Traverse the string character by character.
6. Stop the program.

## Sample Input

Hello

## Sample Output

Length: Hello
