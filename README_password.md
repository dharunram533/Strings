# 25. Password Validation

## Problem Statement

Write a C program to validate whether a password contains at least one uppercase letter, one lowercase letter, one digit, and one special character.

## Algorithm

1. Start the program.
2. Read the password.
3. Initialize flags for uppercase, lowercase, digit, and special character.
4. Traverse every character of the password.
5. If an uppercase letter is found, set the uppercase flag.
6. If a lowercase letter is found, set the lowercase flag.
7. If a digit is found, set the digit flag.
8. If a special character is found, set the special character flag.
9. Check all four flags.
10. If all conditions are satisfied, the password is valid.
11. Otherwise, the password is invalid.
12. Stop the program.

## Sample Input

Abc@1234

## Sample Output

Password is valid.
