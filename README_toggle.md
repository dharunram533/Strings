## 38. Toggle the Case of Every Alphabet

### Problem Statement
Write a C program to toggle the case of every alphabet in a string using a user-defined function.

### Algorithm
1. Start.
2. Declare a character array.
3. Read the string using `fgets()`.
4. Call the user-defined function.
5. Traverse each character of the string.
6. If the character is lowercase, convert it to uppercase.
7. If the character is uppercase, convert it to lowercase.
8. Leave digits, spaces and special characters unchanged.
9. Print the modified string.
10. Stop.

### Sample Input
HeLLo WoRLd

### Sample Output
hEllO wOrlD
