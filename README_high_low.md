# 8. Convert Uppercase to Lowercase

## Problem Statement

Write a C program to convert all uppercase letters in a company name into lowercase.

## Algorithm

1. Start the program.
2. Read the company name.
3. Traverse each character.
4. Check whether the character is an uppercase letter.
5. Convert it into lowercase.
6. Display the modified company name.
7. Stop the program.

## Sample Input

ABC COMPANY

## Sample Output

abc company
