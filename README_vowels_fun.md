# 32. Count Vowels Using User-Defined Function

## Problem Statement

Write a C program to count the number of vowels in a string using a user-defined function.

## Algorithm

1. Start the program.
2. Read the string.
3. Pass the string to a user-defined function.
4. Traverse each character.
5. Check whether the character is a, e, i, o, or u.
6. Increment the vowel count when a vowel is found.
7. Display the number of vowels.
8. Stop the program.

## Sample Input

Education

## Sample Output

Number of Vowels: 5
