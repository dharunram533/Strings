# 3. Count Vowels and Consonants

## Problem Statement

Write a C program to count the number of vowels and consonants in a customer's feedback message.

## Algorithm

1. Start the program.
2. Declare a character array to store the feedback.
3. Read the feedback message.
4. Initialize vowel and consonant counters to zero.
5. Traverse each character in the string.
6. Check whether the character is an alphabet.
7. If it is a vowel, increment the vowel counter.
8. Otherwise, increment the consonant counter.
9. Display the number of vowels and consonants.
10. Stop the program.

## Sample Input

Good product

## Sample Output

Vowels: 4
Consonants: 7
