# 9. Count Character Occurrences

## Problem Statement

Write a C program to count how many times a particular character appears in a paragraph.

## Algorithm

1. Start the program.
2. Read the paragraph.
3. Read the character to be searched.
4. Initialize a counter to zero.
5. Traverse the paragraph.
6. Compare each character with the given character.
7. Increment the counter when a match is found.
8. Display the number of occurrences.
9. Stop the program.

## Sample Input

Paragraph: banana is a fruit
Character: a

## Sample Output

Character 'a' occurs 5 times.
