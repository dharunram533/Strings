37. CONVERT UPPERCASE LETTERS INTO LOWERCASE

## PROBLEM STATEMENT:
Write a C program to convert all uppercase letters into lowercase using a user-defined function.

## ALGORITHM:
1. Start.
2. Declare a character array.
3. Read the string using fgets().
4. Call the user-defined function.
5. Traverse the string character by character.
6. Convert each uppercase character into lowercase using tolower().
7. Print the modified string.
8. Stop.

## SAMPLE INPUT:
HELLO WORLD

## SAMPLE OUTPUT:
hello world
