## 52. Check Whether a Substring Exists

### Problem Statement

Write a C program to determine whether a substring exists within another string without using strstr().

### Algorithm

1. Start the program.
2. Read the main string.
3. Read the substring.
4. Pass both strings to a user-defined function.
5. Traverse the main string.
6. Compare the substring with the characters of the main string.
7. If all characters of the substring match consecutively, the substring exists.
8. Otherwise, the substring does not exist.
9. Display the result.
10. Stop the program.

gram

### Sample Output

Substring exists in the string.
