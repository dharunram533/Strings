# 29. Compare Two Strings Using User-Defined Function

## Problem Statement

Write a C program to compare two strings using a user-defined function without using strcmp().

## Algorithm

1. Start the program.
2. Read two strings.
3. Pass both strings to a user-defined function.
4. Compare the characters of both strings one by one.
5. If all characters are equal and both strings end at the same position, the strings are identical.
6. Otherwise, the strings are different.
7. Display the result.
8. Stop the program.

## Sample Input

Hello
Hello

## Sample Output

Strings are equal.
