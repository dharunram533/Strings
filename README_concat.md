# 13. Concatenate First Name and Last Name

## Problem Statement

Write a C program to concatenate a first name and last name without using strcat().

## Algorithm

1. Start the program.
2. Read the first name.
3. Read the last name.
4. Find the end of the first name.
5. Add a space after the first name.
6. Copy the last name after the space.
7. Add the null character at the end.
8. Display the full name.
9. Stop the program.

## Sample Input

First Name: Dharun
Last Name: Ram

## Sample Output

Full Name: Dharun Ram
