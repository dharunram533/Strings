# 15. Check Character Exists in String

## Problem Statement

Write a C program to check whether a given character exists in a string entered by the user.

## Algorithm

1. Start the program.
2. Read the string.
3. Read the character to be searched.
4. Traverse the string.
5. Compare each character with the given character.
6. If a match is found, indicate that the character exists.
7. If no match is found, indicate that the character does not exist.
8. Stop the program.

## Sample Input

String: computer
Character: p

## Sample Output

Character 'p' exists in the string.
