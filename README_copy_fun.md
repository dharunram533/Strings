# 27. Copy String Using User-Defined Function

## Problem Statement

Write a C program to copy one string into another using a user-defined function without using strcpy().

## Algorithm

1. Start the program.
2. Read the source string.
3. Pass the source and destination strings to a user-defined function.
4. Copy each character from the source string to the destination string.
5. Add the null character at the end.
6. Display the copied string.
7. Stop the program.

## Sample Input

Hello

## Sample Output

Copied String: Hello
