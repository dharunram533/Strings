## 45. First Occurrence of Character
## Problem Statement

Write a C program to find the first occurrence of a character in a string using a user-defined function and display its position.

## Algorithm
1.Start the program.
2.Read the string.
3.Read the character to be searched.
4.Pass the string and character to the user-defined function.
5.Traverse the string from the beginning.
6.Compare each character with the given character.
7.When the first match is found, return its position.
8.If the character is not found, return -1.
9.Display the position of the first occurrence.
10.Stop the program.
11.Sample Input

## Sample input
String: banana
Character: a

## Sample Output

First occurrence of 'a' is at position 2.
