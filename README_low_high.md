# 7. Convert Lowercase to Uppercase

## Problem Statement

Write a C program to convert all lowercase letters in an email subject into uppercase without using strupr().

## Algorithm

1. Start the program.
2. Read the email subject.
3. Traverse each character.
4. Check whether the character is a lowercase letter.
5. Convert the lowercase letter into uppercase.
6. Display the modified subject.
7. Stop the program.

## Sample Input

meeting tomorrow

## Sample Output

MEETING TOMORROW
