# 4. Count Words in a Sentence

## Problem Statement

Write a C program to count the number of words in a sentence entered by a user.

## Algorithm

1. Start the program.
2. Declare a character array to store the sentence.
3. Read the sentence using fgets().
4. Initialize the word counter to zero.
5. Traverse the sentence.
6. Identify the beginning of each word.
7. Increment the counter for every new word.
8. Display the total number of words.
9. Stop the program.

## Sample Input

C programming is easy

## Sample Output

Number of Words: 4
