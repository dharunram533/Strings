# 20. Frequency of Every Alphabet

## Problem Statement

Write a C program to count the frequency of every alphabet present in a sentence.

## Algorithm

1. Start the program.
2. Read the sentence.
3. Initialize frequency counters for the alphabets.
4. Traverse every character in the sentence.
5. If the character is an alphabet, update its corresponding frequency.
6. Display the frequency of each alphabet that appears.
7. Stop the program.

## Sample Input

banana

## Sample Output

a: 3
b: 1
n: 2
