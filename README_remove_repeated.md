# 24. Remove Repeated Consecutive Characters

## Problem Statement

Write a C program to remove all repeated consecutive characters from a string. Example: "boook" → "bok".

## Algorithm

1. Start the program.
2. Read the string.
3. Traverse the string from the beginning.
4. Compare each character with the previous character.
5. If the current character is different from the previous character, keep it.
6. If it is the same, ignore it.
7. Display the resulting string.
8. Stop the program.

## Sample Input

boook

## Sample Output

bok
