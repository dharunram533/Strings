# 5. Reverse a Password

## Problem Statement

Write a C program to reverse a password string and display the reversed version.

## Algorithm

1. Start the program.
2. Read the password into a character array.
3. Find the length of the password.
4. Start from the last character.
5. Display the characters in reverse order.
6. Stop the program.

## Sample Input

Password123

## Sample Output

Reversed Password: 321drowssaP
