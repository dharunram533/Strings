36. CONVERT LOWERCASE LETTERS INTO UPPERCASE

## PROBLEM STATEMENT:
Write a C program to convert all lowercase letters into uppercase using a user-defined function.

## ALGORITHM:
1. Start.
2. Declare a character array.
3. Read the string using fgets().
4. Call the user-defined function.
5. Traverse the string character by character.
6. Convert each lowercase character into uppercase using toupper().
7. Print the modified string.
8. Stop.

## SAMPLE INPUT:
hello world

## SAMPLE OUTPUT:
HELLO WORLD
