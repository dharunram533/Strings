## 51. Check Whether a Character Exists

### Problem Statement

Write a C program to determine whether a character exists in a string using a user-defined function.

### Algorithm

1. Start the program.
2. Read the string.
3. Read the character to be searched.
4. Pass the string and character to a user-defined function.
5. Traverse the string character by character.
6. Compare each character with the given character.
7. If a match is found, return true.
8. If the end of the string is reached without a match, return false.
9. Display the result.
10. Stop the program.

### Sample Input

Programming
g

### Sample Output

Character exists in the string.
