# 23. Extract Uppercase Letters

## Problem Statement

Write a C program to extract only the uppercase letters from an alphanumeric string.

## Algorithm

1. Start the program.
2. Read the alphanumeric string.
3. Traverse each character.
4. Check whether the character is between A and Z.
5. Display only the uppercase characters.
6. Stop the program.

## Sample Input

AbC12DeF45

## Sample Output

ACDF
