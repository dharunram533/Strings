# Count Alphanumeric Characters in a String

## Problem Statement

Write a C program to read a string and count the number of alphanumeric characters (A-Z, a-z, and 0-9) present in the string.

## Algorithm

1. Start the program.
2. Declare a character array to store the string.
3. Initialize a counter variable to 0.
4. Read the string using fgets().
5. Traverse the string character by character.
6. Check whether each character is an uppercase letter, lowercase letter, or digit.
7. If the character is alphanumeric, increment the counter.
8. Display the total count of alphanumeric characters.
9. Stop the program.

## Sample Input

Hello123 World!

## Sample Output

Count = 11
