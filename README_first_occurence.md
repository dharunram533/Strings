# 16. First Occurrence of Character

## Problem Statement

Write a C program to find the first occurrence of a character in a string and display its position.

## Algorithm

1. Start the program.
2. Read the string.
3. Read the character to be searched.
4. Traverse the string from the beginning.
5. Compare each character with the given character.
6. When the first match is found, record its position.
7. Display the position.
8. Stop the program.

## Sample Input

String: banana
Character: a

## Sample Output

First occurrence of 'a' is at position 2.
