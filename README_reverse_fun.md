# 30. Reverse String Using User-Defined Function

## Problem Statement

Write a C program to reverse a string using a user-defined function.

## Algorithm

1. Start the program.
2. Read the string.
3. Pass the string to a user-defined function.
4. Find the length of the string.
5. Start from the last character.
6. Display the characters in reverse order.
7. Stop the program.

## Sample Input

Hello

## Sample Output

Reversed String: olleH
