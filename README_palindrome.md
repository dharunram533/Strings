# 6. Palindrome String

## Problem Statement

Write a C program to check whether an entered word is a palindrome. Example: "LEVEL".

## Algorithm

1. Start the program.
2. Read the word.
3. Find its length.
4. Compare the first character with the last character.
5. Continue comparing characters from both ends.
6. If all corresponding characters are equal, the word is a palindrome.
7. Otherwise, it is not a palindrome.
8. Display the result.
9. Stop the program.

## Sample Input

LEVEL

## Sample Output

LEVEL is a palindrome.
