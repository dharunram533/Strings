# 33. Count Consonants Using User-Defined Function

## Problem Statement

Write a C program to count the number of consonants in a string using a user-defined function.

## Algorithm

1. Start the program.
2. Read the string.
3. Pass the string to a user-defined function.
4. Traverse each character.
5. Check whether the character is an alphabet and not a vowel.
6. Increment the consonant count.
7. Display the number of consonants.
8. Stop the program.

## Sample Input

Hello World

## Sample Output

Number of Consonants: 7
