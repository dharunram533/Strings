# 21. Check Anagram Strings

## Problem Statement

Write a C program to determine whether two strings are anagrams of each other. Example: "listen" and "silent".

## Algorithm

1. Start the program.
2. Read the first string.
3. Read the second string.
4. Count the frequency of each character in both strings.
5. Compare the character frequencies.
6. If all frequencies are equal, the strings are anagrams.
7. Otherwise, they are not anagrams.
8. Display the result.
9. Stop the program.

## Sample Input

listen
silent

## Sample Output

The strings are anagrams.
