## 50. Last Occurrence of a Character

### Problem Statement

Write a C program to find the last occurrence of a character using a user-defined function.

### Algorithm

1. Start the program.
2. Read the string.
3. Read the character to be searched.
4. Pass the string and character to a user-defined function.
5. Traverse the string from the beginning to the end.
6. Whenever the character is found, store its position.
7. Continue until the end of the string.
8. Display the position of the last occurrence.
9. Stop the program.

### Sample Input

Hello World
l

### Sample Output

Last occurrence of 'l' is at position 10.
