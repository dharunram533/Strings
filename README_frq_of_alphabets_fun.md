## 53. Frequency of Every Alphabet

### Problem Statement

Write a C program to count the frequency of every alphabet in a string using a user-defined function.

### Algorithm

1. Start the program.
2. Read the string.
3. Pass the string to a user-defined function.
4. Create an array of 26 elements and initialize all elements to zero.
5. Traverse the string character by character.
6. Check whether the character is an alphabet.
7. Increment the corresponding frequency.
8. Display the frequency of each alphabet that occurs.
9. Stop the program.

### Sample Input

Hello

### Sample Output

H : 1
e : 1
l : 2
o : 1
