# 17. Last Occurrence of Character

## Problem Statement

Write a C program to find the last occurrence of a character in a file name.

## Algorithm

1. Start the program.
2. Read the file name.
3. Read the character to be searched.
4. Traverse the complete string.
5. Whenever the character is found, update its position.
6. After traversal, the stored position will be the last occurrence.
7. Display the position.
8. Stop the program.

## Sample Input

File Name: document.txt
Character: t

## Sample Output

Last occurrence of 't' is at position 10.
