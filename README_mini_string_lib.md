## 55. Mini String Library

### Problem Statement

Write a C program to implement your own mini string library by creating user-defined functions for length, copy, compare, concatenate, reverse, uppercase conversion, lowercase conversion, palindrome checking, and character search. Demonstrate each function from main().

### Algorithm

1. Start the program.
2. Read the required strings and character.
3. Create a user-defined function to find the length of a string.
4. Create a user-defined function to copy one string to another.
5. Create a user-defined function to compare two strings.
6. Create a user-defined function to concatenate two strings.
7. Create a user-defined function to reverse a string.
8. Create a user-defined function to convert a string to uppercase.
9. Create a user-defined function to convert a string to lowercase.
10. Create a user-defined function to check whether a string is a palindrome.
11. Create a user-defined function to search for a character.
12. Call all the functions from main().
13. Display the results of each operation.
14. Stop the program.

### Sample Input

Hello
World
l

### Sample Output

Length : 5
Copied String : Hello
Strings are different.
Concatenated String : HelloWorld
Reversed String : olleH
Uppercase String : HELLO
Lowercase String : hello
String is not a palindrome.
Character 'l' found at position 3.
