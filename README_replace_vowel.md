# 22. Replace Vowels with *

## Problem Statement

Write a C program to replace every vowel in a sentence with the '*' character.

## Algorithm

1. Start the program.
2. Read the sentence.
3. Traverse each character.
4. Check whether the character is a vowel.
5. Replace every vowel with '*'.
6. Display the modified sentence.
7. Stop the program.

## Sample Input

Hello World

## Sample Output

H*ll* W*rld
