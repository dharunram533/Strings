## 54. Compress Consecutive Duplicate Characters

### Problem Statement

Write a C program to compress consecutive duplicate characters in a string using a user-defined function.

Example: "aaabbccccd" becomes "abcd".

### Algorithm

1. Start the program.
2. Read the string.
3. Pass the string to a user-defined function.
4. Traverse the string from the beginning.
5. Compare each character with the previous character.
6. Copy the character only if it is different from the previous character.
7. Continue until the end of the string.
8. Add the null character at the end.
9. Display the compressed string.
10. Stop the program.

### Sample Input

aaabbccccd

### Sample Output

abcd
