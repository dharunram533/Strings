# 10. Replace Character in a Sentence

## Problem Statement

Write a C program to replace every occurrence of a given character with another character in a sentence.

## Algorithm

1. Start the program.
2. Read the sentence.
3. Read the character to be replaced.
4. Read the new character.
5. Traverse the sentence.
6. Whenever the old character is found, replace it with the new character.
7. Display the modified sentence.
8. Stop the program.

## Sample Input

Sentence: banana
Character to replace: a
New character: o

## Sample Output

bonono
