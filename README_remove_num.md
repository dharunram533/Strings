# 18. Remove Digits from String

## Problem Statement

Write a C program to remove all digits from a mixed string. Example: "AB123CD45".

## Algorithm

1. Start the program.
2. Read the mixed string.
3. Traverse each character.
4. Check whether the character is a digit.
5. Ignore the digit characters.
6. Keep all non-digit characters.
7. Display the resulting string.
8. Stop the program.

## Sample Input

AB123CD45

## Sample Output

ABCD
