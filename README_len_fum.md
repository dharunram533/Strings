# 26. String Length Using User-Defined Function

## Problem Statement

Write a C program to find the length of a string using a user-defined function. Do not use strlen().

## Algorithm

1. Start the program.
2. Read a string from the user.
3. Pass the string to a user-defined function.
4. Traverse the string until the null character is reached.
5. Count each character.
6. Return the count.
7. Display the length of the string.
8. Stop the program.

## Sample Input

Hello

## Sample Output

Length: 5
